운명의 서재 AI 사주운세 V2.0
================================

이 패키지는 V1의 정적 화면을 개선해 다음을 포함합니다.
- 양력/음력 입력(윤달 별도 지정은 미지원)
- lunar-javascript 기반 사주 네 기둥 계산
- AI 풀이 API 서버 코드(api/interpret.js)
- 종합 사주, 오늘의 운세, 재물·직업운, 연애·대인관계, 2027년 운세 프롬프트
- 인쇄/PDF 저장
- API 키를 브라우저에 노출하지 않고 서버 환경변수로 사용

중요한 한계
-----------
현재는 만세력의 기초 네 기둥을 계산하는 시제품입니다.
음력 윤달 별도 지정, 진태양시, 절기 경계 검증, 야자시 처리, 오행·십성·지장간·합충형파해·대운·세운의 정밀 계산은 아직 완성되지 않았습니다.
AI는 계산되지 않은 요소를 추측하지 않도록 제한되어 있습니다.
따라서 지금 버전의 풀이를 전문 명리 상담 수준의 정통 감정으로 광고하거나 유료 확정 서비스로 판매하면 안 됩니다.
2027년 운세도 개인별 세운 계산이 추가되기 전까지는 참고 조언 수준입니다.

스마트폰만 있는 경우
-------------------
1. 이 ZIP을 휴대폰에 다운로드합니다.
2. 휴대폰의 파일 앱에서 압축을 풉니다.
3. 웹 배포는 GitHub와 Vercel 계정 연결이 필요합니다. 휴대폰 브라우저에서도 가능하지만, 파일 업로드/편집은 PC보다 불편할 수 있습니다.
4. Vercel에서 새 프로젝트를 만들고 이 프로젝트 폴더를 배포합니다.
5. Vercel 프로젝트 Settings > Environment Variables에 아래 값을 추가합니다.
   OPENAI_API_KEY = 본인의 OpenAI API 키
   OPENAI_MODEL = gpt-4.1-mini (선택, 기본값과 동일)
6. Redeploy(재배포) 후 사이트에서 AI 풀이를 시험합니다.

보안
----
- API 키를 index.html에 붙여 넣지 마세요.
- API 키를 채팅창이나 공개 저장소에 올리지 마세요.
- OpenAI API 사용료는 ChatGPT 구독과 별도일 수 있습니다. API 계정의 결제/사용량 한도를 확인하세요.
- 사용자의 생년월일은 민감한 개인정보에 준해 최소 수집하고, 이 시제품은 서버에 출생정보를 저장하지 않습니다.
